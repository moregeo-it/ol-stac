getGeoTiffStyleFromAsset(asset, sourceInfo, defaultColormap){Object | null}

util.js, line 1339 
import {getGeoTiffStyleFromAsset} from 'ol/util';

Creates a WebGLTileLayer style for a GeoTIFF layer from the STAC metadata.

A usable render from the render extension (see isUsableRender) defines the complete visualization: for single-band data its colormap provides the colors (see createColormapStyle for the supported forms), applied over the range from its rescale.

Without a usable render, the classification extension (classification:classes) provides the coloring for single-band categorical data (not applied to floating point data, which is assumed to be continuous), and continuous single-band data is colored with the given default colormap (over the value range from the statistics).

When no style is returned, the value ranges from getGeoTiffSourceInfoFromAsset stretch the data (to grayscale for a single band) instead. The returned styles operate on the raw data values, i.e. the GeoTIFF source must be configured with normalize: false.

Name Type Description
asset module:stac-js~Asset

The STAC asset
sourceInfo SourceInfo

The source info (for the selected bands).
defaultColormap Array.<(module:ol/color.js~Color|string)> | null | undefined

The colors of the colormap for continuous single-band data, evenly distributed over the value range.
Returns:
A WebGL tile layer style object, or null

getGeoZarrStyleFromAsset(asset, sourceOptions, defaultColormap){Object | null}

util.js, line 797 
import {getGeoZarrStyleFromAsset} from 'ol/util';

Creates a WebGLTileLayer style for a GeoZarr layer from the STAC metadata.

A usable render from the render extension (see isUsableRender) defines the complete visualization: the value range comes from its rescale and single-band colors from its colormap (see createColormapStyle for the supported forms).

Without a usable render, a default visualization is derived from the general STAC metadata: the value range to stretch comes from the statistics of the rendered bands (or the asset), the classification extension (classification:classes) provides the coloring for single-band categorical data (not applied to floating point data, which is assumed to be continuous), and continuous data is colored with the given default colormap or stretched to grayscale (consistent with single-band COGs).

Name Type Description

The asset to read the metadata from.
sourceOptions Object

The GeoZarr source options (to determine the rendered bands).
defaultColormap Array.<(module:ol/color.js~Color|string)> | null | undefined

The colors of the colormap for continuous single-band data, evenly distributed over the value range.
Returns:
A WebGLTileLayer style, or null if the metadata provides none.

toContinuousBBox(bbox){Array.<number>}

util.js, line 57 
import {toContinuousBBox} from 'ol/util';

Makes a bounding box continuous for use as an (OpenLayers) extent.

Bounding boxes that cross the antimeridian have a western longitude that is larger than the eastern longitude (as defined by RFC 7946, section 5.2). For those, the eastern longitude is shifted by +360 so that the extent is continuous across the antimeridian (i.e. minX <= maxX).

Accepts both 2D (four values) and 3D (six values) bounding boxes and always returns a 2D extent (four values).

Name Type Description
bbox Array.<number>

The bounding box in lon/lat degrees.
Returns:
The continuous 2D bounding box.
