They are rendered in the given order, i.e. the last data source is rendered on top. Changing the data sources keeps the layers of the data sources that are still shown, so they are not reloaded when another data source is added, removed or moved. tags: "stac, stac item, geotiff, cog, assets, web map links, xyz" ---
